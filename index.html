Build: Create Variables

Complete three drag-and-drop declarations and three typed declarations. Use the exact variable name requested.

Classroom format: var circleSize = 40;
var creates the variable, circleSize is its name, and 40 is its starting value. Use a semicolon at the end in this practice lab. JavaScript also permits some statements without one.

Naming Practice: Clear and Valid Names

camelCase: start lowercase; capitalize the first letter of each later word: circleSize.
snake_case: use lowercase words joined by underscores: circle_size.
Both are valid JavaScript naming styles. Names cannot contain spaces or hyphens, start with a digit, or use reserved keywords such as var. Names are case-sensitive: circleSize and CircleSize are different names.
