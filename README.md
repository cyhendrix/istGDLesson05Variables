# Lesson 05: Variables

IST Unit 03 practice lab for Fitzgerald High School College and Career Academy.

## Activities and scoring
- Identify: six vocabulary matches.
- Build: three draggable declarations and three typed declarations.
- Naming Practice: four typed variable names and four multiple-choice naming questions.
- Apply: four visual code-prediction questions.
- Debug: five corrections for declaration syntax, naming, capitalization, and declaration order.

29 scored items, converted to a percentage. This lesson adds practice requested by the teacher in camelCase and snake_case. Both conventions are valid JavaScript; they are distinguished from syntax rules. The lab checks exact requested names and values, accepts flexible spaces in typed declarations, and requires a final semicolon as a classroom format. JavaScript's optional-semicolon behavior is acknowledged in the instructions.

## Student workflow
Student information appears first with separate first/last name fields and all four blocks. Activity questions, choices, word banks, and code tiles are randomized per attempt. A perfect first check completes a tab; otherwise students have one additional check. Feedback appears after checking, using light green/dark green or light red/dark red. Browser progress is saved automatically. Reset is available only after a confirmed final-grade submission and never removes recorded grades.

## Deployment
Enable GitHub Pages from main, root folder. The main file is index.html.

Grade submission remains disabled until the shared Game Design Grade Submission Apps Script is replaced with grade-submission.gs and deployed as a new version. It supports Lessons 01 through 05, including the new Naming Practice section. After deployment, set SUBMISSION_READY=true in index.html and test final submission, spreadsheet recording, and reset. Add the lesson to the hub after approval.
